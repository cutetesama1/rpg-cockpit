# 0.991beta 更新日志

- 新增文字展示速度：设置 → 阅读 → 文字展示速度，支持5—200字符/秒和即时显示；“立即显示”可直接读完已收到内容。只控制前端展示，不减速网络、模型生成、后端结算或状态提交。
- 新增圆形“纠正AI”入口。展开后普通行动输入与建议让位，支持带图标的“更改叙述 / 更改数值”切换，两种草稿分开保留。
- 叙述纠正通过叙事模型修订最近一段正文，不推进回合、不再扣费结算。可选择让后续叙述继续遵循视角、语气等要求。
- 数值纠正使用新的corrector角色，只读取本次纠正说明、当前数值、字段定义和资源绑定，不携带聊天历史。默认复用有效后端连接，也可在高级模型设置指定独立连接。
- 数值提交逐项校验字段、类型、有限数值、绝对上下限和本次原文依据；整批验证后写入账本，拒绝部分提交。玩家主动纠正不套用普通行动的每回合增量额度，但不能突破字段绝对范围或修改字段定义。
- 新增纠正回执、重复请求保护、过期状态保护、适当的撤销。撤销剧情回合会撤回依附于该回合的纠正，保存和读档保留纠正与有效叙述偏好。
- 电脑端新增完整双方对话历史：自己的行动、AI回复、纠正说明及修订稿均可向上查看，并随存档恢复。
- Android versionCode升至31；用户显示版本0.991beta，npm/Tauri为兼容格式0.99.1-beta，Python为0.99.1b0。

真模型效果取决于所接服务；本次使用隔离模拟响应验证调用链，没有使用付费LLM或安装到Android真机。

## 下载与升级

- Android：大多数手机选择arm64；通用包兼容arm64与x86_64，x86_64包适合对应模拟器。
- Windows：安装包或完整解压便携ZIP，两个exe保持同一目录。升级前退出旧版。
- 模型服务需自行配置；应用没有内置大语言模型。
- 这是Beta测试版。使用现有公开版原创静态示意立绘；完整分层动作、表情和衣物图层可自行接入授权素材。代码与素材许可分别保留。
- 安卓安装包沿用原公开版签名；应用数据仍保存在原用户目录。
