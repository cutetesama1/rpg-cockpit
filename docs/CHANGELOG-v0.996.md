# v0.996 · 后端精度与安卓兼容

本次按用户要求复用已保留的原始导出包，**没有重新编译、重签名或修改安装包内容**。GitHub 发布号与下载文件名统一为 **v0.996**，每版递增 0.001；原包内部仍为 **0.991beta-accuracy-preview**，Android 安装序号 **33**。

## 本版内容

- 后端同时读取本轮玩家输入与叙述，继续以权威状态为依据，不携带会话历史。
- 放宽唯一名称匹配；模糊识别、临时物品 ID、估值与确认入包。
- 隐藏式裁定入口、是/否/搁置问题、背包，以及角色卡 4 MB 解析限制移除。

## 下载

- 日常使用建议下载本轮最新的 [v0.999](https://github.com/cutetesama1/rpg-cockpit/releases/tag/v0.999)；其他版本保留为历史功能归档，不是要求依次安装。
- 多数安卓手机选择 arm64；通用 APK 包含 arm64 与 x86_64。旧包的系统安装序号可能较低，无法直接覆盖较新的本地版本。
- Windows 安装版或完整解压便携 ZIP，升级前关闭正在运行的旧版。
- 新版角色卡 HTML 解释器 0.995beta 不属于本次“0.991 后缀更新”范围；没有单独发布多人/穿透联机测试版。
