# RPG 驾驶舱 v0.7.3 · 结算稳定性更新

本次重点修复容易造成整回合回滚的协议问题，重新整理叙事端与后端提示词，并改善结算失败后的修正反馈。相较上一个公开版本 v0.7.1，同时补入自定义立绘的动作、表情与饰品状态接口。

## 主要修复

- **明确模型分工**：叙事端只生成正文和选项；清除技能付款说明、内置前置模板中残留的状态工具与状态栏输出指令。后端在完整正文生成后，读取当前状态和本回合正文，统一提交一次结算草案。
- **修复“不确定即整批失败”**：无法确认的事项单独记录并在聊天、结算日志显示“待确认”，相关未知状态保留原值；其余已确认且合法的变化正常提交。
- **完善草案重试**：校验失败时向后端提供上一份完整草案、具体操作位置、错误码和原因，要求保留其他有依据的变化，修正后重新提交完整草案，减少漏结算与重复扣费。
- **改善剧情事实兼容性**：普通剧情事实支持中文名称、长名称和已有的 `story.` 前缀，映射为稳定标识；不会将普通事实升级成系统标记或关卡解锁。
- **保留事务与护栏**：提交前预校验暂存事件。非法字段、错误证据、超限数值、负库存、非法技能和外观操作仍会拒绝整份草案；不通过吞掉错误假装结算成功。
- **补齐公开版内置技能包**：补入标准 300 技能 ZIP 与作者模板 ZIP，修复公开源码中“一键安装标准技能库”依赖的归档缺失问题。

## 外观与开发接口

- 自定义立绘支持注册动作、表情、视线、嘴型、眼泪、饰品和前景/背景状态，以及程序动作表现。
- 衣物目录和立绘目录按本次正文筛选，保留当前选项，减少向结算器重复发送无关目录。
- 改善共享外观模板升级、旧存档恢复和撤销后的外观字段兼容性。
- 公开版默认继续使用原创静态示意角色；第三方完整立绘库和本地演示截图未随公开源码或安装包分发。完整换装、表情画面需要自行接入有权使用的素材。

## 升级说明

后端仍不携带历史聊天上下文。正常回合只进行一次后端结算调用；草案不合法时最多额外修正一次，两次均不合法仍会回滚并记录原因。

已有世界使用新的运行时结算协议，无需为提示词修复重新建档。用户自定义世界提示词、模型配置与存档不覆盖。升级前退出旧版，再覆盖安装或完整解压新便携包。

应用不内置大语言模型，需自行配置兼容的 API 或本地模型服务。配置与存档保存在本机，没有自动跨设备云同步。
