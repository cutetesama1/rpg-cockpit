# v0.995 · 立绘衣物与头发对齐

- 修正衣物分片、袖子与身体的遮挡、定位和映射处理。
- 修正耳侧头发层级，更新导入及几何审计工具。

## 版本与安装

- 本版对应原 `RPG-Cockpit-Clothing-Hair-Fix` 的功能更新，统一数字版本为 **0.995**；不再以功能后缀区分版本。
- Android 版本名 `0.995`，安装序号 `41`，沿用原公开版签名；多数手机用 arm64，通用包含 arm64 与 x86_64。
- Windows 安装包与便携包的系统版本为 `0.995.0`（打包格式要求三段数字），应用内显示 `0.995`。
- 模型服务和 NPC 语音服务由用户自行配置，本项目没有内置大模型。
- 这是开发阶段预发布；数字版本号不代表全部功能已经稳定。旧版页面和下载链接保留。

## 公开素材与兼容说明

沿用公开仓库的原创静态示意立绘，不附带私有完整分层衣物/头发素材或用户角色卡。衣物动作与对齐更新提供引擎、目录校验、表现动作和导入工具；实际画面取决于自行接入的授权素材。
所有本次重建的版本均采用 Android 原生依赖校验与 16 KB 对齐修复，避免重新分发已知启动故障。没有单独发布多人联机或穿透联机预览包；后续源码快照可能保留此前已有的实验代码。
