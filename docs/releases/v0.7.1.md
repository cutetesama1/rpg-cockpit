## RPG 驾驶舱 0.7.1

首次提供与公开源码配套的 Windows 桌面安装包、便携包与 Android APK，采用新的星门书页图标。

### 选哪个文件

| 设备 | 文件 |
| --- | --- |
| 大多数 Android 手机（Android 10+，arm64） | `RPG-Cockpit-v0.7.1-arm64.apk` |
| Android 通用包（arm64 / x86_64） | `RPG-Cockpit-v0.7.1.apk` |
| Android x86_64 模拟器 | `RPG-Cockpit-v0.7.1-x86_64.apk` |
| Windows 10/11 64位安装版 | `RPG-Cockpit-v0.7.1-Windows-x64-Setup.exe` |
| Windows 64位免安装版 | `RPG-Cockpit-v0.7.1-Windows-x64-Portable.zip` |

Windows 便携版请完整解压后运行 `rpg-cockpit.exe`，与 `rpg-sidecar.exe` 放在同一目录。安装版提供卸载入口；桌面窗口使用 Microsoft Edge WebView2 Runtime。无需另装 Python 或 Node.js。

### 包含的功能

- 自定义世界书、叙事提示词与独立结算提示词。
- 每回合完成叙述后，后端仅凭本回合正文、当前状态与规则结算。
- 可调整基础数值名称、上下限、用途绑定与角色设定。
- 内置300项分级武技/魔法，支持 ZIP 技能库导入与作者模板。
- 流式叙事、分行对白、聊天历史、存读档与撤销。
- 电脑与手机布局、四套主题、壁纸、字号及新的应用图标。

应用不内置大语言模型，需在设置里配置兼容的模型 API 或自行部署的本地服务。配置与存档留在本机，没有自动跨设备云同步。

### 本次公开素材范围

安装包与公开源码一致，默认角色为**原创静态示意图**。未分发开发演示使用的第三方完整立绘库；衣物、动作、表情的后端状态接口保留，完整画面需要自行接入有权使用的素材。代码和原创图形使用 Apache-2.0，第三方依赖保留各自许可。

- 前端17项行为检查、TypeScript检查和生产构建通过。
