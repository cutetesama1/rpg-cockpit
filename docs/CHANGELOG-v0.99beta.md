# 0.99beta 更新日志

本版汇总自v0.7.3以来通往1.0.0的四阶段更新：

- 可选剧情导演与后端骰子：候选、触发与确定结果分离，结果留档且重复请求不会重新掷骰。
- 玩家裁定中心：确认、否决、修改、搁置和历史；状态差异可预览，经校验后提交并支持适当撤销。
- 角色卡V2/V3兼容：JSON、PNG/APNG和CHARX导入、预览及字段映射，保留不支持字段的原始数据。


- 新增可选人格角色卡模式，支持批量预览、多选加入当前世界 NPC，仅接收姓名、性格与喜好，隔离卡内提示词。
- 世界构筑新增人格人物库、出场条件和导演复查计划。人格模式联动剧情导演，正式检定通过后才向叙事 AI 公开人物。
- 实现第四阶段动态世界书：人物、关系、地点、秘密与关键事实持续维护，复用现有后端结算调用。
- 新增事实版本、原文来源、归档、显式揭晓、秘密隔离、历史记录、存档恢复和事务撤销。手动草案接入玩家裁定中心。
- 世界书单条校验失败进入内部裁定，其他合法资源变化可继续落账；世界书不替代 HP/MP、冷却与库存。
- Android 文件选择器支持一次多选；沿用原有签名，versionCode 升至30。



## 下载与升级

- Android：大多数手机选择arm64；通用包兼容arm64与x86_64，x86_64包适合对应模拟器。
- Windows：安装包或完整解压便携ZIP，两个exe保持同一目录。升级前退出旧版。
- 模型服务需自行配置；应用没有内置大语言模型。
- 这是Beta测试版。使用现有公开版原创静态示意立绘；完整分层动作、表情和衣物图层可自行接入授权素材。代码与素材许可分别保留。
- 安卓安装包沿用原公开版签名；应用数据仍保存在原用户目录。
