# 文字展示、AI纠正与对话历史

## 文字速度

设置 → 阅读 → 文字展示速度。0为即时显示，其他档位为每秒显示的字符数；默认60。设置保存在当前设备。正在显示时也可调整，点“立即显示”可显示所有已经收到的正文。模型尚未产生的内容不能提前显示。历史存档不会重新打字，后端状态会在提交完成时立即刷新。

## 纠正入口

平时右下方保留圆形笔形按钮；手机上在普通输入区上方。开局或当前操作完成后点击，即展开纠正输入区并收起正常行动输入。关闭后恢复普通输入，草稿仍保留。键盘快捷键为Ctrl/⌘+Enter；Esc关闭。

“更改叙述”：例如“改为第一人称，让不同人物的话分别换行”。只修订当前最后一段正文，不重新推进剧情、不再次结算，也不修改HP、金币等权威值。勾选“后续叙述也遵循”时，后续叙事会读取这次文风/视角要求；再提交新的长期要求可替换旧要求。原文和修订稿都保留在历史中，模型后续上下文使用有效修订稿。

“更改数值”：例如“刚才已经充分休息，将体力恢复至上限；金币减少5”。新的独立纠正器只读这段说明与当前数值，不回顾旧正文，不补算旧伤。应写明对象和想要的结果；有歧义时不会猜造字段。只允许内容包已定义的数值字段，不修改技能、衣物、标记、场景、库存或世界书；这些内容继续通过已有游戏结算、世界构筑和裁定机制处理。

纠正成功后会显示差异与“撤销本次纠正”。此后已有新的剧情或状态变化时，直接撤销会被拒绝，避免把后续结果覆盖回旧值；可再写一条新的纠正说明。操作不增加游戏回合或消耗技能冷却，撤销上一剧情回合时会一并撤回该回合附属的纠正。

## 模型配置

默认情况下，新corrector调用使用有效后端模型连接；叙事纠正仍使用叙事模型。每次调用的请求与提示词独立。

设置 → 高级角色配置 → 数值纠正使用独立连接。开启后可单独选择provider、model等配置，与常规后端是否独立无关；关闭回到有效后端连接。独立纠正请求不携带历史、世界书或之前的AI正文。

## 桌面历史

电脑叙事区域现与手机一样显示双方消息。向上滚动可查看自己的行动、使用的技能与AI回答；你在上方阅读时不会强制跳到最底部。读档恢复的是账本中真实记录；更旧存档如果没有记录当时输入，不会凭空补写玩家消息。

## 接口

POST /api/corrections 与 /api/corrections/stream：pack_id、request_id、revision、mode(narrative/state)、instruction、persist。
revision取/api/state.correction_revision，request_id每个新操作唯一，网络重试沿用同一完整请求。
POST /api/corrections/undo：pack_id、receipt_id。

数值模型唯一工具为correct_values：changes:[{field,value,evidence}]和explanation。value为最终数值，evidence为本次说明的连续原文。账本事件correction.applied使用负数辅助事务号；权威数值通过tool.applied投影，撤销通过turn.rolled_back复用既有链路。
