# 通往 1.0.0

当前开发交付：0.99beta，第一至第四阶段，并包含可选人格 NPC 模式。以下进度按已经实现的功能标记，不将后续阶段提前计入版本完成情况。

## 第一阶段：剧情导演 AI 与骰子系统

- [x] 可选导演，默认关闭；可复用叙事模型或独立配置模型。
- [x] 读取相关世界书、NPC性格、已发生事件、玩家行动和未解决线索。
- [x] 以场景变化、重要事件、线索更新和显式请求触发，配置调用间隔。
- [x] 严格分开候选、触发与结果；未触发候选及未选中分支不进入叙事上下文。
- [x] 后端确定性骰子与概率检定，稳定事件ID、记录、参数冲突拒绝和重复触发保护。
- [x] 失败重试、叙事重写、撤销及存档恢复不为同一检定生成新结果。
- [x] 导演不直接修改数值、物品、技能、标记或玩家行动。
- [x] 设置面板、手动骰子、内部审计的显式查看和秘密默认隔离。

## 第二阶段：玩家裁定中心

- [x] 复用待确认事项，建立结构化、可追踪的裁定队列。
- [x] 确认、否决、修改、搁置及历史记录。
- [x] 后端复核、事务提交、幂等、防过期操作、差异和撤销。
- [x] 区分公开事项和内部秘密；保留来源回合与裁定事件编号。

## 第三阶段：SillyTavern 角色卡 V2/V3

- [x] JSON/PNG/APNG/CHARX 导入、预览、字段映射和错误报告。
- [x] 描述、性格、场景、可选开场白、示例对话和嵌入式世界书；扩展明确保留并提示兼容范围。
- [x] 原始文件/JSON 保留与导出，未支持字段明确提示，复用当前世界书系统。

兼容范围：字面关键词、大小写、常驻、启停、次级关键词与排序已接入；正则及专属装饰指令停用并提示。多媒体和扩展脚本只保留，不自动转换为分层立绘或执行。详见 P26。

新增：可选人格模式，批量提取姓名、独立性格、明确喜好；原卡提示词、描述、场景、开场白和世界书不参与。启用后强制剧情导演，安排未来回合复查及正式出场。

## 第四阶段：动态世界书

- [x] 人物、关系、地点、秘密、关键事实的动态维护与来源记录。
- [x] 不替代HP、MP、技能冷却、物品数量等权威状态。
- [x] 优先复用当前后端结算调用和工具，不默认增加每回合模型调用。

多人联机是独立方向，本轮未改变单人会话结构，也未声称完成联机。


公开版采用原创静态示意角色，可自行接入授权素材。源码和安装包的测试范围以对应版本发布页为准。
