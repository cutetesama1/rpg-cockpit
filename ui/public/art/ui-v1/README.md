# UI art v1 — 星穹庭院

Generated with the built-in image_gen tool on 2026-10-18, specifically for this project.
No reference image, game artwork or existing logo was supplied to generation.
Exact prompts are saved in prompts.json. PNG files are unmodified copies of the generated originals.

- night-background.png: full-page wallpaper; readable empty center.
- portrait-alcove.png: decorative background behind the existing sprite canvas.
- compass-crest.png: transparent header/sidebar ornament. Alpha is preserved.

Controls, text, frame lines, state bars and navigation icons remain HTML/CSS/SVG.
Original sprites and character compositing are independent of these decorative assets.
