# Code and assets

The Apache-2.0 license applies to this source export's first-party code and original
sample graphics. Third-party dependencies retain their own licenses and are
installed by the user; their licenses are not replaced by this project's Apache-2.0 license.

This source export excludes the Degrees of Lewdity sprite tree used by the private
development build, all private QA screenshots, prebuilt wheels, signed binaries,
API credentials, local saves and Git history. The private sprite tree's existing
credit file identifies separate CC BY-NC-SA terms; it is not included or relicensed.

The public default sprite is an independently drawn, fully clothed schematic
placeholder. Its purpose is to demonstrate the renderer configuration. It does not
reproduce the private sprite library's hairstyle, expression or wardrobe artwork.
Developers can supply their own licensed images and corresponding sprites.json.

Decorative UI images under ui/public/art/ui-v1 were generated for this project.
Their original prompt and provenance files are retained in the same directory.


## Reused historical release binaries

The 0.992–0.999 GitHub releases reuse existing local exports unchanged. Some of those binaries include separately licensed DoL-derived portrait parts and DecoMod decorations. Their original licenses and credits are retained in the binaries and attached ASSET-NOTICES.zip. They are not relicensed under Apache-2.0. The public source tree continues to use original sample artwork; source and archived binaries have different asset sets. See each release for the original internal version and SHA-256 provenance.
